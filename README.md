# Mercado Correntino

Prototipo inicial de un marketplace para comercios de Corrientes Capital.

## Archivos
- `index.html`: estructura de la web.
- `styles.css`: estilos adaptables a celular y computadora.
- `app.js`: búsqueda, categorías, productos de ejemplo y formulario de contacto.
- `manifest.json`, `icon.svg`, `sw.js`: archivos iniciales para una experiencia tipo app.

## Publicación gratis con GitHub Pages
1. Crear un repositorio público llamado `mercado-correntino`.
2. Subir todos estos archivos a la raíz del repositorio (no subir la carpeta contenedora).
3. En Settings > Pages, elegir Deploy from a branch, branch `main` y carpeta `/(root)`, y guardar.
4. Esperar a que GitHub Pages publique el sitio.

## Importante
Los productos son ejemplos. El formulario abre WhatsApp con los datos para preparar una consulta; todavía no guarda publicaciones compartidas ni tiene cuentas, base de datos o cobros. No ingreses datos personales sensibles.
